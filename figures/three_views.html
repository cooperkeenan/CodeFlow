Three views of a node

One decision in a Django codebase, shown at three depths — the map that locates it, the control flow that explains it, and the source that proves it.

Decision Flowscope: whole repository

Where does this codebase branch?

The always-visible map. Static analysis finds every fork in the code; an LLM judges which of them a person would genuinely reason about, and writes the question each one asks. Entry points are green, decisions amber, outcomes and effects follow the arms out. Nothing is deleted to make the page fit — detail is demoted a level and reached through the + control.

Flowchartscope: one class

How does that decision execute?

Choosing isolate turns the node into a frame: the symbol on the left, the control flow of the selected method on the right.

Code viewscope: one method

And what does the source say?

The same frame, toggled. The left column is unchanged — only the right swaps between diagram and code.

Each view is the same node at a different magnification. The map never loses provenance, and the frame never loses the map — closing it returns the node to exactly where it sat.
